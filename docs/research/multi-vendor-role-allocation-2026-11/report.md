# 역할별 3사 모델 배분 리서치 종합

- 날짜: 2026-11-17
- 방식: Claude Opus + Exa(학술, 공식 문서, 벤치마크), Antigravity Argon high + Google Search(실무, 산업 사례) 독립 병렬 검색 뒤 교차검증. Codex는 사용량 소진으로 제외.
- 원본: `claude-exa.md`, `agy-google.md` (같은 폴더), 질의는 `queries.md`

## 두 출처가 합의한 것

1. 모델을 따로 둘 만큼 차이가 나는 역할 경계는 적다.
   - 탐색(읽기 전용, 빠른 모델), 분해와 판단(계획, 설계), 실행(구현, 테스트), 검증(리뷰, 보안), 리드, 소통.
   - 공식 하네스 기본값도 굵다. Codex는 default, worker, explorer. Claude Code는 Explore, Plan, general-purpose. Antigravity Orchestrator는 계획과 리뷰를 Carbon 또는 Argon, 구현과 테스트를 Hydrogen에 둔다.
   - planner와 architect, implementer와 tester를 서로 다른 모델로 나눌 근거는 없다. 역할 페르소나 자체는 정확도를 바꾸지 않는다(Wharton 2025-12).
2. 분해와 판단 쪽에 강한 모델을 두는 효과가 실행 쪽보다 크다. 위임 쪽 용량 확대 이득이 실행 쪽의 약 4배("Think Big, Search Small", 2026-07). 실행과 탐색은 작은 모델로도 정확도가 유지된다.
3. 리드는 강한 모델이 맞지만 가치는 검증 가능한 판단에서 나온다. 의견만 내는 감독 계층은 토큰 51.5% 증가, 품질 하락(loop-back 실험 2026-09). 워커의 날것 로그 대신 압축 요약만 받게 한다.
4. 소통은 둘로 나뉜다. 상태 중계와 알림은 빠른 모델(Haiku, Luna, Hydrogen low), 사용자 대면 보고는 중상위 모델과 문체 검사기 조합.
5. 다중 계층 오케스트레이션은 전체 대화록 대신 압축 산출물만 주고받아야 비용 폭발을 막는다. 계층별 모델 배정을 잰 자료는 없다.
6. 작은 모델이 빠른 것은 effort가 낮을 때만이다. Haiku 5.5 max 첫 답 토큰 184초, Luna 기본 effort는 코드 리뷰를 거의 못 한다.
7. 프롬프트만 보고 모델을 고르는 라우터는 약하다. 효과가 난 것은 작업 단계나 궤적을 신호로 쓰는 라우팅, 계획자와 실행자가 제어를 주고받는 구조, 실트래픽 A/B다.
8. 역할별 1위 모델은 벤치마크마다 바뀌고 상위권 격차가 신뢰구간 안인 경우가 많다. 고정 배정은 성능보다 비용과 지연으로 고르는 편이 근거와 맞는다.

## 한쪽만 낸 것 (반론 없음)

- 벤더 전환 비용(agy): 세션 도중 다른 벤더로 바꾸면 프롬프트 캐시가 무효화되고 도구 호출 스키마 차이로 파서가 깨진다. 벤더는 워커를 띄울 때 고르고 세션 안에서는 effort만 조절하는 방식이 주류.
- 비용 대비 성능(Exa, Terminal-Bench 4.1): Sol은 1위보다 4.9%p 낮고 비용은 Opus 5.5의 약 1/8. Carbon은 1.3%p 낮고 Opus의 약 30%. Fable 5.2는 Opus 5.5와 동률인데 비용 3.5배.
- 약관(Exa): Anthropic은 구독 OAuth를 Claude Code와 claude.ai 밖에서 쓰는 것을 금지. 공식 CLI를 여러 개 띄워 오가는 방식은 해당 없음.
- 긴 세션 규칙 준수는 모든 모델이 약하다(HANDBOOK.md 최고 36.2%). 모델 선택보다 외부 검증으로 강제하는 장치가 중요.

## 충돌하는 것

- 교차 벤더 리뷰
  - 찬성: Greptile(다른 벤더가 재현율 2~3%p 높음, 리뷰 제품 회사 자체 측정), 자기 선호 편향 연구(arXiv 2604.06996, 원문 확인: 생성자가 실패한 루브릭에서 자기 출력이면 통과 판정 확률이 최대 50% 넘게 높음).
  - 반대: Stephens 사전등록 연구(같은 모델 새 세션 대조군을 두면 4개 중 3개 체크포인트에서 교차 벤더 가설 실패), JHU(리뷰어가 작성자보다 약하면 91.4%에서 82.8%로 하락).
  - 정리: 이득 대부분은 새 맥락의 두 번째 시선. 리뷰어는 작성자보다 약하면 안 된다. agy 보고서는 2604.06996을 "같은 가족" 결함 승인으로 넓혀 적었으나 원문은 "자기 출력"이다.
- debugger 위치: agy는 실행 쪽(구현, 테스트와 묶음), Exa는 판단 쪽(planner, architect와 묶음).
- 글쓰기와 디자인 분리: agy는 프런트엔드 시각 설계가 필요할 때만 designer 분리, Exa는 글쓰기와 디자인 1위 모델이 구현 1위와 달라 분리 근거가 있다고 봄.
- 글쓰기 품질: LMArena(사람 선호) Carbon 1542, Argon 1532, Opus 5.5 1528. AI Writing Benchmark(AI 판정) Sol 95.3, Opus 92.8, Terra 86.1, Argon 63.2.
- 출력 속도 수치는 집계 사이트마다 크게 달라 1차 출처 미확인.
- 가격: agy는 Terra를 $1.42/$7.11로 적었으나 공식 가격은 $1/$5(Exa). 공식을 따른다.
